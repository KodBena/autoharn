— the original 6-case suite did not cover the anchor-matters shape at all and stayed green

trailing `\s*$` end-anchor removed, i.e.

    re.compile(r"^/row\s+\d+(\s+\d+)*")   # BROKEN: no end anchor

instead of the shipped

    re.compile(r"^/row\s+\d+(\s+\d+)*\s*$")

CONSEQUENCE: a prompt that STARTS with a valid `/row <id> [...]` shape but carries real
additional request text after it now matches too, and the hook silently swallows the entire
prompt — including the part that was never a `/row` command at all.

    : decision\nstatement                   : mock row 1325 statement text"}

The whole "...and also please refactor this whole file while you are at it" request is gone —
blocked and replaced with a row dump the user never asked for, on a prompt that was never a
bare `/row` command. This is exactly the "a hook that mangles an ordinary prompt is worse than
no hook" hazard design constraint 2 names, made concrete.
