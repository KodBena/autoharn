DISCLOSED SCOPE (module docstring, SCRATCH-WORLD SCOPE NARROWING): this is a narrow, best-effort
recognizer for the ONE self-contained shape actually witnessed causing the leakage this session --
a Bash command that, in its ENTIRETY, launches a seen-red/ fixture script. A scratch-touching
command in any OTHER shape (a raw psql call against a scratch host, a fixture invoked some other
way, one leg of a chained command) is NOT suppressed here and still relies on the standing,
already-working `env -u PGOPTIONS <cmd>` consumer-side idiom (left standing, out of scope for this
pass). This suite's e/f cases exist specifically to prove that: they show the SAME shell-
metacharacter / mixed-command shape still gets injected exactly as before, so this fix can never be
mistaken for a general "skip near seen-red/" rule.
